================================================================================
COMPARISON: EMG vs NCV PIPELINES
================================================================================

┌─────────────────────────────────────┬─────────────────────────────────────┐
│ EMG PIPELINE                        │ NCV PIPELINE                        │
├─────────────────────────────────────┼─────────────────────────────────────┤
│                                     │                                     │
│ Raw Signal (.txt)                   │ CSV Features (.csv)                 │
│   ↓                                 │   ↓                                 │
│ Bandpass Filter (20-500 Hz)        │ Handle Missing Values               │
│   ↓                                 │   ↓                                 │
│ Notch Filter (50 Hz)                │ Normalization (Z-score)             │
│   ↓                                 │   ↓                                 │
│ Segmentation (40ms)                 │ Augmentation (Gaussian)             │
│   ↓                                 │   ↓                                 │
│ STFT (window=256)                   │ Reshape (n_features, 1)             │
│   ↓                                 │   ↓                                 │
│ Spectrogram (256×256)               │ 1D Input                            │
│   ↓                                 │   ↓                                 │
│ 2D CNN                              │ 1D CNN / LSTM                       │
│   ↓                                 │   ↓                                 │
│ Classification                      │ Classification                      │
│                                     │                                     │
│ Time: 2-3 hours                     │ Time: 30-60 minutes                 │
│ Accuracy: 60-75%                    │ Accuracy: 70-85%                    │
│ GPU: Required                       │ GPU: Optional                       │
│ Memory: 8-16 GB                     │ Memory: 2-4 GB                      │
│                                     │                                     │
└─────────────────────────────────────┴─────────────────────────────────────┘
