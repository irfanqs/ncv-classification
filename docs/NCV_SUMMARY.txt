================================================================================
KEY DIFFERENCES: EMG vs NCV
================================================================================

EMG System:
- Data: Time-series signal (raw waveform)
- Preprocessing: STFT → Spectrogram (complex)
- Input: 2D image (256×256)
- Training: 2-3 hours
- Accuracy: 60-75%
- GPU: Required

NCV System:
- Data: Tabular (CSV with features)
- Preprocessing: Normalization only (simple)
- Input: 1D vector (4-7 features)
- Training: 30-60 minutes
- Accuracy: 70-85%
- GPU: Optional

================================================================================
MODELS:
================================================================================

1. 1D CNN
   - Conv1D layers untuk feature extraction
   - Best untuk spatial patterns

2. LSTM
   - Bidirectional LSTM
   - Best untuk temporal patterns

3. CNN-LSTM Hybrid
   - CNN + LSTM kombinasi
   - Usually best overall performance
